🔍 TapeLens

Circuit Verifier for TapeOut on X Layer. A TapeOut circuit is a netlist of NAND gates (+ LATCH cells) sold as a Circuit NFT — but buyers and PoD miners can't see what logic it actually implements. TapeLens proves it: it re-evaluates any NAND netlist for every input combination and checks it against the claimed truth table, on-chain.
